저장과 파일 내보내기 안내

입력 내용은 저장 전에도 미리보기에 반영됩니다. ‘Save · 공개 사이트에 저장’을 눌러야 사이트에 적용됩니다. 저장이 완료되면 모든 방문자가 최신 내용을 보게 됩니다. 백업 다운로드는 선택 사항입니다.

한국어와 영문을 따로 편집하고 Save하면 함께 공개됩니다. 이미지·연락처는 공통입니다.

소개와 연락처

20MB 이하 PDF · Save를 누르면 업로드됩니다.

작업 편집

가로 1600px 이하로 저장합니다. JPG/PNG/WebP 지원. 실제 작업 이미지를 추가하면 요약 그래픽 대신 표시됩니다.

성과와 과정

성과는 한 줄마다 「수치 | 설명」 형식으로 입력합니다. 예: 7.1만 | 릴스 조회수한 줄에 「image 또는 video | 공개 URL | 영상 미리보기 이미지 URL (선택) | 설명」을 입력하세요. 이미지도 세 번째 자리는 비워 두세요. 영상은 자막이 포함된 최종 작업물을 권장합니다.

이력 목록

활동명과 분류를 직접 수정하고, 날짜는 달력에서 선택하세요. 수정한 내용은 오른쪽 Resume에 바로 나타납니다.
